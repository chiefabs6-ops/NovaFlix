# NovaFlix Cinematic UI (0.4.0) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every NovaFlix screen and popup takes the "Cinematic Premium" look the owner approved on 2026-10-23, with no change to what the app does. Released as 0.4.0 after the owner's PC and stick checks.

**Architecture:** Most of the work is in the WindowXML layouts (`resources/skins/Default/1080i/*.xml`) and the generated textures (`tools/make_assets.py`). Control IDs and controllers stay. The Python changes only feed the new layouts with data they need:
- details of the focused card;
- TMDB title logos;
- labelled hero fields;
- dialog button labels;
- download stats;
- source quality badges;
- genre tile pictures;
- styled replacements for Kodi's OK box and pick list.

**Tech Stack:** Python 3 stdlib, Kodi 21 WindowXML (Estuary fonts only), Pillow (developer machine only, `tools/make_assets.py`), pytest with `tests/fakes`.

**Spec:** the concept previews the owner approved:
- **Where:** `docs/superpowers/specs/2026-10-23-cinematic-ui/round4/index.html` (20 screens), plus `round3/a-cinematic-premium.html` (Home).
- **Shared values:** `round4\cinematic.css` holds the values below.
- **Copied in Task 1** from the session scratchpad, so the spec stays with the plan (the photographs in `img` are not shipped).

## Global Constraints

- **Fonts:** only Estuary fonts (`tests/test_layouts.py::ESTUARY_FONTS`). An add-on cannot ship fonts, so the concepts' serif titles become TMDB title logos (Task 3), with `font52_title` text when a title has none.
- **Font mapping:**
  - `font52_title`: page titles;
  - `font45_title`: page headings;
  - `font30_title`: row titles and buttons;
  - `font13`: body;
  - `font12`: meta;
  - `font10`: the small grey labels over values ("Rating", "Year");
  - nothing smaller.
- **Colours (ARGB)**, the only ones the layouts use:
  - ground `FF05070A`;
  - surfaces `FF0C1015` (s1), `FF141A21` (s2), `FF1E2630` (s3);
  - text `FFFFFFFF` (ink), `FFD3D8DF` (ink2), `FF8F98A4` (ink3);
  - accent `FF00A6D6` (cyan), `FF35CDF5` (cyan-hi), `FF001820` (text on cyan);
  - status `FF3FD28F` (ready), `FFF5B04F` (needs download), `FFFF6B7A` (blocked);
  - dimming: black at `80`–`E6` alpha.
  - **No purple, violet or blue anywhere.** The logo image keeps its own colours.
- **Shapes:**
  - cards and posters: 10 px corners;
  - buttons: full pills, 66 px tall;
  - dialogs: 22 px corners;
  - focus ring: 3 px (white on cards, cyan on buttons);
  - focus zoom: 104 % on cards, 105 % on buttons;
  - no glow, no gradient buttons.
- **Motion:** fades 200 ms; focus zoom 150 ms; menu open 250 ms.
- **Layout grid:**
  - content left edge x=184 on every app-window view;
  - the collapsed rail is 112 wide;
  - the open menu covers x 0–760 with the dark fade.
- **IDs:** every ID in `gui/ids.py` keeps its meaning. New IDs are added to `ids.py` and `WINDOW_IDS`.
- **No `<include>`** (`test_no_unexpanded_placeholders`). Repeated item layouts are written out in full, generated by a script when a layout appears more than twice.
- **Copy:** new user-facing text goes into `strings.po` with new ids from 30500 up. Never hard-code English in Python.
- **Test command:** `.venv\Scripts\python -m pytest -p no:cacheprovider -o addopts=""` (734 passing at the start). Known flaky: `tests/test_phone_keyboard.py` socket tests (rerun once).
- **Testing:** the owner tests by hand on the PC (`tools/dev_kodi.py install`) and on the stick at the end. No JSON-RPC driving and no screenshots of Kodi.

## Review Focus

1. **Cached titles from before 0.4.0** have no `logo` key. Opening Home or a title page must not fail; the title shows as text until the cache refreshes. Pinned by `test_library.py::test_cached_title_without_logo_loads` (Task 3).
2. **A title with no backdrop, no logo and no plot** (common in Airing today):
   - the hero and grid peek show the title text on the plain ground;
   - empty labelled fields hide, with no stray "Rating" label over nothing.
   - Pinned by `test_cards.py::test_card_details_leave_missing_fields_empty` (Task 2) and `test_layouts.py::test_labelled_fields_hide_when_empty` (Task 5).
3. **The menu opening from any view** (Home, grid, related) must give focus back to where it was on Right, and Back from the open menu closes it before leaving the app. Pinned by `test_layouts.py::test_rail_returns_focus_to_each_view` (Task 4).
4. **Download progress when TorBox reports no size or speed:**
   - the stats that are missing hide;
   - no "about 0 min left", and no division by zero.
   - Pinned by `test_gui_dialogs.py::test_progress_stats_skip_missing_values` (Task 11).
5. **The genre pictures job failing** (offline, TMDB error) must leave the tiles usable with their names and no picture, and must not report an error popup. Pinned by `test_gui_lists.py::test_genre_pictures_failure_keeps_tiles` (Task 8).
